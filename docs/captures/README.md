# Captures

Screenshots and recordings used as evidence in `docs/kiro.md` and the submission. One file per moment, named for what it shows.

Rules:
- Sample content only (`samples/human-heart.txt` and the like). Never real notes, never a key, never a personal name.
- Name files `<what>-<where>-<width>.png`, for example `design-critic-ingest-1280.png`.
- Page snapshots that the Playwright MCP server saves automatically (`page-*.yml`) are git-ignored. Only screenshots you keep on purpose are committed.
